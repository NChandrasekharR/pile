Every tab you close, kept as a reading list.

Pile is a free Chrome extension that saves each tab the moment you close it, so you can close tabs, and whole windows, without losing anything. Search them, triage them, export them. Everything stays in your browser.

Install from GitHub Chrome Web Store listing coming soon

What it does

Close tabs freely. Come back to them on purpose.

Catches every tab

Each tab is saved the moment it closes. Tabs lost to a browser quit are picked up from Recently Closed on the next launch.

Windows stay together

Close a window of fifty tabs and they're kept as one group, not fifty unrelated rows.

Duplicates folded

Tracking parameters are stripped, so the same article closed four times is one row marked “closed 4×”.

Search and filter

Search titles and links, filter by site, and sort by date, site, title or how often you closed it.

Triage mode

One link at a time, full screen. Open it, keep it, mark it done, delete it or skip, all from the keyboard.

Export anytime

Markdown grouped by site, raw JSON, or a bookmarks file any browser can import.

Keyboard

Built to be driven from the keyboard.

  • / search
  • jk move
  • o open in background
  • s keep
  • e mark done
  • x delete
  • u undo
  • t triage mode
  • AltShiftP open Pile

Private by design

Your reading list never leaves your computer.

Pile stores what you close in your browser's local storage, on this machine. It has no host permissions, makes no network requests, and has no account, no server and no analytics. Site icons come from the browser's own cache.

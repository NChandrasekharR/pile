Help with Pile

Found a bug or have an idea? Open an issue on GitHub. Include your Chrome version and what you did right before it happened.

Common questions

How do I install Pile?

Get it from the Chrome Web Store. It works in Chrome and in other browsers that install from the Chrome Web Store, such as Brave, Arc and Edge. Install it before you next quit the browser: Pile pulls in whatever is in Recently Closed when it's installed, and that list is cleared on restart.

How do I open Pile?

Click the Pile icon in the toolbar, or press Alt + Shift + P. If the icon is hidden, click the puzzle-piece Extensions button and pin Pile.

The keyboard shortcut doesn't work.

Another extension may already use it. Go to chrome://extensions/shortcuts and set a different shortcut for “Open Pile”.

I quit the browser and some tabs didn't show up.

Quitting the browser closes tabs without telling extensions. Pile picks them up from the browser's Recently Closed list the next time the browser starts. That list holds only 25 entries, though a whole window counts as one entry. Click Pull from browser to check it again by hand.

Some pages never appear in Pile.

On purpose: Pile only keeps web pages (http and https). Browser pages like chrome://settings, extension pages and local files are skipped.

I deleted something by mistake.

Press u, or click Undo in the message at the bottom of the screen.

Where is my reading list stored?

In your browser's local storage, on this computer only. It isn't synced and is never sent anywhere. See the privacy policy.

How do I move my pile to another computer or browser?

Pile doesn't sync. Use Export and choose Bookmarks file; any browser can import it. Markdown and JSON exports are there too if you want the list somewhere else.

What happens if I uninstall Pile?

Your reading list is deleted with it. Export first if you want to keep it.
